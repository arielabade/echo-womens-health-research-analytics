# Data Availability

The original research data, source spreadsheets, and raw notebook outputs are not included in the public repository.

This project involved evaluation materials from a health-related research and training context. To protect participant privacy and comply with responsible research-data handling practices, the repository publishes only:

- non-identifiable summaries;
- aggregate statistical results;
- portfolio-safe visualizations and notebooks generated from aggregate values;
- methodological descriptions that do not expose participants or restricted records.

The original files remain locally preserved in `source-documents/`, which is excluded from Git through `.gitignore`.

Any synthetic or aggregate values used in the public notebook are intended for portfolio demonstration only and should not be treated as participant-level research data.
